# Tongjiang Lab

English | [简体中文](README.zh-CN.md)

**Free, interactive 3D science lessons for high school — physics, chemistry, biology and geography.**

Try them online: **https://lab.tongjiang.app**

There are 50 lessons so far. Each one is a **single self-contained HTML file** of about 1 MB: double-click to open it, and it works offline, on a projector or on an interactive whiteboard. Every lesson is one 3D world with a live control console, a guiding question and a step-by-step path a teacher can follow from start to finish.

Science content draws on public data, primary literature and general scientific conclusions; all lesson text and visuals are original. Each lesson lists related NGSS* performance expectations and OpenStax sections, with links to the source pages only. The lesson interface is currently in Chinese; other languages are planned.

## How to use

- **Online**: click **▶ Open lesson** in the tables below. GitHub only shows the source code of an HTML file, so use these links to see the lessons.
- **Offline**: download all lessons as one zip from [Releases](https://github.com/smithjohn78390/tongjiang-lab/releases/latest), or download a single lesson from its page on https://lab.tongjiang.app, then open it in Chrome or Edge. In the zip, open `courses/index.html` to browse every lesson offline (keep `courses/` and `covers/` side by side).
- **Embed**: `<iframe src="https://lab.tongjiang.app/<slug>" width="100%" style="aspect-ratio:16/9;border:0" allow="fullscreen"></iframe>`
- **Data**: [`catalog.json`](catalog.json) lists every lesson with its NGSS* codes, OpenStax sections and steps.
